# ПР-01 · Каталог товаров

Решение: `solution.py` (Python, драйвер pymongo).

## Как запустить

```
pip install pymongo
docker compose run --rm reset        # чистые данные в стенде курса: 21 товар, 120 заказов
python solution.py
```

Сервер: `mongodb://localhost:27017` (другой адрес — переменная `MONGO_URI`).
Читаем базу `shop`, меняем только `sandbox`.

## Что делает программа

**Задача 1. `catalog_page(category, page, per_page, sort_field, desc)`**
возвращает страницу товаров и общее число под фильтром: фильтр собирается по условию,
проекция `sku/title/price/rating` без `_id`, сортировка по двум ключам (поле и `sku`),
`total` считает сервер через `count_documents`, страница за пределами данных — пустой список.

**Задача 2. Приёмка поставки** в `sandbox.products`:
`$inc` по трём артикулам, `insert_many(ordered=False)` для двух новинок с собственным `_id`,
`delete_many` по `SKU-CP-018` (сначала `count_documents` и просмотр), `update_many`
с `free_shipping: true` для аксессуаров.
