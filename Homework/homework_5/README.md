## 1. Какой оператор делает какой раздел отчёта

| Раздел отчёта | Чем сделан в скрипте |
|---|---|
| 1. Требования | Операторов нет: четыре переменные `NAVYKI`, `GOROD`, `POTOLOK`, `OPYT_MESYACEV` и `print`. Из них собираются все фильтры |
| 2. Каждое требование по отдельности | Пять `count_documents` в цикле: `$all`, `$or`, `$lte`, `$elemMatch`, `$exists` |
| 3. Все требования сразу | Один фильтр: `$all` + `$lte` + `$elemMatch` + `$or`. Пары верхнего уровня работают как «и». Затем `sort("salary", 1)` и `count_documents` |
| 4. Должности с Junior | `$regex: "^junior"` и `$options: "i"` |
| 5. Вакансии под ожидание | Точечная нотация `salary.from` с `$lte` и `salary.to` с `$gte` |
| 6. Собеседования за неделю | Полуинтервал `$gte` / `$lt` по полю `when`, дополнительные пары `stage` и `format` |
| 7. Проверка данных | `$exists`, `$not` + `$type`, `$size`, `skills.0` + `$exists`, `$expr` + `$gt`, `$ne` |
| 8. Кто не прошёл отбор | Фильтров нет: `find({})`, причины отказа считает Python (`set(NAVYKI) <= set(skills)` и сравнения полей) |
