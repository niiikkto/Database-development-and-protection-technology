## Письмо 1. Ревью конвейеров

### 1. Выручка доставленных заказов от ноутбуков.

- Решение: есть ошибка — сумма по полю заказа после $unwind — итог повторён в каждой позиции — верно
- Комментарий: После $unwind поле $total дублируется для каждой позиции заказа, а нам нужно считать сумму только по ноутбукам. Суммируй цену позиции с учётом количества ($items.price * $items.qty), а не общий чек заказа.
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $unwind: "$items" },
  { $match: { "items.category": "ноутбуки" } },
  { $group: { _id: null, revenue: { $sum: { $multiply: ["$items.price", "$items.qty"] } } } }
])
```

### 2. Сколько заказов в пути в каждом городе.

- Решение: есть ошибка — $project перед стадией, которой нужно отброшенное поле — верно
- Комментарий: В первом $project ты отбросила поле status, поэтому следующий $match ничего не находит. Убери $project из начала или просто поставь $match первой стадией.
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { status: "в пути" } },
  { $group: { _id: "$delivery.city", orders: { $sum: 1 } } },
  { $sort: { _id: 1 } }
])
```

### 3. Номер первого по дате заказа каждого покупателя из трёх: c-007, c-011, c-018.

- Решение: есть ошибка — $first или $last без $sort перед $group — верно
- Комментарий: $first берёт первый попавшийся документ в порядке хранения, а не по дате. Перед $group обязательно нужно отсортировать заказы по дате (created_at: 1 или date: 1).
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { customer_id: { $in: ["c-007", "c-011", "c-018"] } } },
  { $sort: { created_at: 1 } },
  { $group: { _id: "$customer_id", first: { $first: "$number" } } },
  { $sort: { _id: 1 } }
])
```

### 4. Пять самых дорогих доставленных заказов.

- Решение: есть ошибка — стадии стоят не в том порядке: $limit срабатывает раньше отбора — верно
- Комментарий: Сначала нужно отфильтровать доставленные заказы через $match, а уже потом сортировать и брать топ-5. Иначе ты берёшь 5 самых дорогих заказов вообще и только потом отсеиваешь недоставленные.
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $sort: { total: -1 } },
  { $limit: 5 },
  { $project: { _id: 0, number: 1, total: 1 } }
])
```

### 5. Выручка доставленных заказов по способам оплаты.

- Решение: есть ошибка — путь к полю записан без знака $ — верно
- Комментарий: В _id забыла знак $ перед payment.method, поэтому все заказы сгруппировались в одну кучу под строкой "payment.method". Добавь $ в начало пути.
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  { $group: { _id: "$payment.method", revenue: { $sum: "$total" } } }
])
```

### 6. Сколько штук смартфонов продано в доставленных заказах.

- Решение: есть ошибка — условие на элемент массива проверено до $unwind — проходят заказы целиком — верно
- Комментарий: Если в заказе есть хотя бы один смартфон, до $unwind он пройдёт целиком, и в сумму попадут вообще все товары из этого заказа (чехлы, ноутбуки и т.д.). Фильтровать по категории нужно ещё раз после $unwind.
- Исправленный конвейер:

```js
db.orders.aggregate([
  { $match: { status: "доставлен", "items.category": "смартфоны" } },
  { $unwind: "$items" },
  { $match: { "items.category": "смартфоны" } },
  { $group: { _id: null, qty: { $sum: "$items.qty" } } }
])
```

### 7. Средний чек доставленных заказов в каждом городе, округлённый до рубля, по убыванию.

- Решение: конвейер верный — верно
- Комментарий: сначала фильтрация по статусу, потом группировка по городу с расчётом среднего, округление и сортировка по убыванию. Ошибок нет.

### 8. Три самых продаваемых по штукам товара в доставленных заказах.

- Решение: конвейер верный — верно
- Комментарий: отфильтровала доставленные, развернула массив товаров, корректно просуммировала штуки по каждому названию и взяла топ-3. Всё верно.

### 2. Коллекция products. Средняя цена товаров каждой категории, округлённая до рубля: _id — категория, avg — средняя цена. По возрастанию avg.

```js
db.products.aggregate([
  { $group: { _id: "$category", avg: { $avg: "$price" } } },
  { $project: { avg: { $round: ["$avg", 0] } } },
  { $sort: { avg: 1 } }
])
```

- Результат совпадает с нужным, запусков: 1

### 5. Одним запросом по доставленным заказам: в поле total — массив из одного документа { orders: число заказов }, в поле top — три товара с наибольшим числом штук (_id — название, qty — штуки), по убыванию qty, при равенстве — по названию.

```js
db.orders.aggregate([
  { $match: { status: "доставлен" } },
  {
    $facet: {
      total: [
        { $count: "orders" }
      ],
      top: [
        { $unwind: "$items" },
        { $group: { _id: "$items.title", qty: { $sum: "$items.qty" } } },
        { $sort: { qty: -1, _id: 1 } },
        { $limit: 3 }
      ]
    }
  }
])
```

- Результат совпадает с нужным, запусков: 1
