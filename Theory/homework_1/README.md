# Домашнее задание № 1 · MongoDB: документ, BSON и первая коллекция

МДК.04.01 · Технология разработки и защиты баз данных · ветка `hw-01`

## О работе

Коллекция `shop.orders` — заказы интернет-магазина кофейного оборудования.
В ней пять документов. Форма у них намеренно разная:

- у `A-1002` нет полей `tags` и `promo_code`;
- у `A-1003` есть дополнительное поле `comment`;
- у `A-1004` поле `tags` — пустой массив;
- `promo_code` есть только у `A-1001` и `A-1005`.

Пример документа:

```json
{
  "number": "A-1001",
  "customer": { "name": "Иван Петров", "city": "Ярославль" },
  "items": [
    { "title": "Кофемашина", "qty": 1, "price": 11500 },
    { "title": "Капсулы эспрессо", "qty": 3, "price": 300 }
  ],
  "total": 12400,
  "status": "delivered",
  "tags": ["подарок", "срочно"],
  "promo_code": "WELCOME10",
  "created": { "$date": "2026-09-01T10:15:00Z" }
}
```

Здесь есть вложенный объект (`customer`), массив строк (`tags`), массив
объектов (`items`) и дата (`created`, в базе получит тип Date).

## Что понадобится

- Docker Desktop (для сервера MongoDB 7);
- MongoDB Compass (используемая версия — 1.53.0);
- файлы из этой папки.

## Как подключиться из Compass

1. Запустить Docker Desktop.
2. В папке `stend/` выполнить `docker compose up -d`.
3. Проверить, что сервер работает: `docker ps` — контейнер `hh-mongo` в статусе `Up`,
   порт `27017` проброшен.
4. В Compass нажать **+** рядом с CONNECTIONS (или открыть New Connection).
5. В поле URI ввести `mongodb://localhost:27017`, в поле Name — «Стенд занятия».
6. Нажать **Connect**. В списке слева появятся базы `admin`, `config` и `local`.

Ошибка `ECONNREFUSED 127.0.0.1:27017` означает, что сервер не запущен:
нужно выполнить шаги 1–3 и подключиться заново.

## Как загрузить данные

1. В Compass нажать **+** у соединения «Стенд занятия» (Create database).
2. Имя базы — `shop`, имя коллекции — `orders`, затем **Create Database**.
3. Открыть `shop` → `orders` → **ADD DATA** → **Import JSON or CSV file**.
4. Выбрать файл `seed.json`, формат JSON, нажать **Import**.
5. Проверить счётчик: должно быть **`1 – 5 of 5`**.

Если счётчик показывает 10, импорт выполнен дважды. Нужно очистить коллекцию
(см. ниже) и повторить загрузку один раз.

## Как проверить запросы

Фильтры вводятся в строку запроса на вкладке Documents, выполняются кнопкой
**Find**, очищаются кнопкой **Reset**. Полный разбор — в `queries.md`.

| Что ищем | Фильтр | Результат |
|----------|--------|-----------|
| Точное совпадение | `{ status: "delivered" }` | 2 из 5 |
| Вложенное поле | `{ "customer.city": "Ярославль" }` | 3 из 5 |
| Элемент массива | `{ tags: "подарок" }` | 2 из 5 |
| Сравнение | `{ total: { $gt: 5000 } }` | 3 из 5 |
| Наличие поля | `{ promo_code: { $exists: true } }` | 2 из 5 |

Шестой, намеренно неверный фильтр `{ "customer.city": Ярославль }` (без кавычек)
даёт ошибку разбора: рамка поля краснеет, кнопка Find недоступна, запрос не
уходит на сервер.

## Как удалить коллекцию

**Через Compass:** навести курсор на `orders` в списке слева → значок корзины →
ввести имя коллекции `orders` → **Drop Collection**.

**Через mongosh:**

```
docker exec -it hh-mongo mongosh shop
db.orders.drop()
```

Только очистить документы, оставив коллекцию: `db.orders.deleteMany({})`.
После удаления данные загружаются заново из `seed.json` по инструкции выше.
